核心主体
Runtime 是项目核心；工作台是产品载体；商品运营 Agent 是业务参考实现。
安全原则
模型提出行动，Runtime 在代码侧校验并控制副作用。
恢复原则
写操作不确定时先回查，不把超时当作失败后直接重试。
图中最重要的四条边界
  • Control / Execution 是逻辑职责，不是微服务。
  • Harness 属于 Runtime，但不等于整个 Runtime。
  • Mem0、WeKnora、Langfuse 都不是权威状态源。
  • Eval 在执行链之外，Harness 不是 Eval。
