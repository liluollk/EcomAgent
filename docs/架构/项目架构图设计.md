# 项目架构图设计

> 日期：2026-10-03
> 状态：已确认

## 1. 目标

以单文件 HTML 展示 Agent Runtime 项目的整体结构、核心边界和一次 Run 的执行路径，用于项目讲解、面试展示和架构复盘。图中内容必须与已确认需求及详细设计一致，不新增代码层级或部署单元。

## 2. 受众与单一任务

- 受众：面试官、项目协作者和需要快速理解系统的开发者；
- 单一任务：在两分钟内说明“产品入口、Runtime 控制职责、持久执行、Agent Harness、能力接入、安全边界和 Eval 的关系”。

## 3. 信息结构

```text
Agent 工作台 / FastAPI
    ↓
运行配置与治理
    ↓
Runtime 执行内核
    └── Agent Harness
    ↓
Capability Layer
    ↓
PostgreSQL Authority

Eval 位于右侧旁路，只通过公开接口验证系统。
```

运行配置与治理和 Runtime 执行内核必须放在同一个 Runtime 外框内，并明确标注“逻辑边界，不是微服务”。

## 4. 两种视图

### 4.1 系统架构

展示模块职责与依赖方向。实线表示生产执行或调用，虚线表示配置、观测和 Eval 验证。PostgreSQL 位于底部，作为权限、状态、审计和恢复的唯一权威来源。

### 4.2 Run 执行链

按顺序突出：用户任务、API 命令、Run 执行器、Context、AgentBackend、ToolCall、PreToolUse、Confirmation、Tool 执行、ToolResultProcessor、Operation/Reconciliation、AgentEvent 和工作台恢复。

## 5. 视觉系统

- `Ink #10243E`：正文与 Runtime 主框；
- `Paper #F5F8FC`：页面背景；
- `Panel #FFFFFF`：信息层；
- `Cyan #0B7FAB`：正常执行流；
- `Amber #D67B22`：写安全、确认和副作用边界；
- `Violet #6C5DD3`：Eval、Trace 和非权威外部系统。

标题使用紧凑的系统无衬线字体，技术标签使用 `Cascadia Code / Consolas`。整体采用工程蓝图语言，避免通用仪表盘卡片、装饰性渐变和无意义图标。

## 6. 交互

- “系统架构 / Run 执行链”切换按钮；
- 点击模块后，高亮当前模块及直接关联模块，并在说明区显示职责、输入、输出和边界；
- 支持键盘聚焦和 Enter/Space 选择；
- `prefers-reduced-motion` 下关闭过渡动画；
- 小屏幕改为纵向布局，不丢失层级信息。

## 7. 边界

- 不使用 Mermaid、React、Canvas 或外部 CDN；
- 不展示尚未实现的 Multi-Agent、模型路由、工作流引擎、插件市场或 Artifact Store；
- Mem0、WeKnora 和 Langfuse 只能显示为非权威外部能力；
- Eval 不进入 Runtime 执行链；
- 图中交互只改变展示，不模拟真实 Runtime 状态。

## 8. 验收

- 单文件双击可打开；
- 1440×900 下主图无需横向滚动，文字无重叠；
- 390px 宽度下可阅读；
- 所有核心模块、边界说明和 Run 步骤均可见；
- 交互切换、模块选择、键盘操作和重置功能可用；
- HTML 不引用外部资源，控制台无错误。
