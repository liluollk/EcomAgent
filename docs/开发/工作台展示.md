# 工作台展示与截图维护

## 展示设计

工作台面向多店铺商品运营，重点呈现「查询 → 比价 → 人工确认 → 执行记录」。使用深蓝侧栏、浅灰画布、蓝色操作按钮和琥珀色确认状态；商品价格变化作为视觉中心，避免用无依据的营收和成功率装饰页面。

真实工作台和演示入口共用基础视觉样式。演示入口 `/?demo=1` 使用独立的本地示例数据，不读取登录令牌、不调用 API，也不修改店铺数据；普通入口继续使用原有登录与后端链路。

## 本地预览

在 `apps/workbench` 执行 `npm ci`、`npm run dev`，打开 `http://localhost:5173/?demo=1`。页面刷新会重置示例状态。真实工作台使用 `/`，依赖配置见[本地环境](本地环境.md)。

启动前端后，在 `apps/workbench` 的另一个终端执行：

```bash
npx playwright install chromium
npm run capture:demo
```
