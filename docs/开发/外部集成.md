# 外部集成

本文档记录 MCP/WeKnora、Mem0 与 Langfuse 三类外部集成的接入方式、降级行为与本地端到端(E2E)验证步骤。所有外部集成都是非权威的:授权、Runtime 状态与写操作事实只来自 PostgreSQL 与 Runtime 服务,集成失效不改变 Run 的权威状态。

## 1. MCP 与 WeKnora

- 依赖:`mcp`(Python SDK,见 `pyproject.toml`);Adapter 在 `adapters/mcp/`。
- Source 接入:远程 MCP Server 走 HTTPS(JSON-RPC),`EndpointPolicy` 先做 SSRF 校验(仅 HTTPS、allowlist、禁私网/元数据地址);本地 stdio Source 只通过部署级 Server Key 选择预注册命令,不接受前端/请求传入的命令。
- Schema 版本化:`McpSourceSync.sync()` 按 canonical Schema Hash 创建新 `ToolVersion`;MCP Server 声明的 effect/permission 一律忽略,新版本 `enabled=False`(`LOCAL_CLASSIFICATION_REQUIRED`),必须经本地受信 `classify()` 绑定副作用与权限后才启用。Schema 或描述变化都会触发重新分类。
- WeKnora:独立部署,本仓库只保存连接配置并作为普通 MCP Source 接入;检索结果只进入 Tool Message(带来源的不可信数据),不会复制其知识库能力。
- 降级语义(`McpToolHandler.invoke`):必需知识源不可用 → `SOURCE_UNAVAILABLE`;可选源不可用 → `DEGRADED`(无数据返回);协议/工具错误 → `TOOL_ERROR`。均不修改 Run 权威状态。
- 相关测试:`tests/adapters/mcp/`。

## 2. Mem0 长期记忆(Outbox)

- 依赖:`mem0ai`;Adapter 在 `adapters/mem0/`,权威记录在 PostgreSQL `memory_records`。
- 只保存已确认的偏好/反馈/决策/经验;权限、资源范围、价格规则、凭据等执行关键事实禁止入库(`MemoryService.accept` 确定性拒绝)。
- 生命周期:纠正产生新 Revision(`supersedes_id` 指向旧记录,旧记录置 `SUPERSEDED`);删除写 Tombstone(`DELETED`);到期由 Worker `expire_due()` 置 `EXPIRED`。检索结果按本地 ID/Revision/生命周期/有效期过滤后才注入 Context。
- 同步:写入/删除产生 `MEMORY_UPSERT`/`MEMORY_DELETE` Outbox 行,`OutboxWorker` 短租约领取,失败指数退避重试、超预算置 `DEAD`;Mem0 完全失效不回滚任何已完成 Run。
- API:`/api/workspaces/{id}/memories…`,仅当前 Actor 可查询/纠正/删除自己的记忆。
- 相关测试:`tests/runtime/memory/`、`tests/adapters/mem0/`、`tests/apps/api/test_memories.py`。

## 3. Langfuse Trace(Outbox)

- 依赖:`langfuse`;Adapter 在 `adapters/langfuse/`(HTTP Ingest 实现 + Protocol)。
- Run/Backend/Tool/Request 事件映射为 trace/span(`trace_id=run_id`);导出前经 `runtime/observability/redaction.py` 字段级脱敏(敏感键名 + 密钥形态值),Secret 不进 Trace。
- 导出走 `TRACE_EXPORT` Outbox,失败只改变 Outbox 状态(重试/DEAD),不改变 Run;挂接点为 `runtime/observability/trace_outbox.enqueue_trace_export`。
- 相关测试:`tests/adapters/langfuse/`。

## 4. 本地 E2E 验证

E2E 走演示入口 `apps.api.demo`(ScriptedBackend + Mock 平台,无真实模型/平台依赖)。
入口不同不靠开关,靠 compose 的 `command`:演示用 `docker-compose.demo.yml` 覆盖。

```bash
# 1. 启动完整服务(postgres + demo api;api 启动前自动执行迁移)
docker compose -f docker-compose.yml -f docker-compose.demo.yml up -d --build postgres api

# 2. 前端检查与单测
npm --prefix apps/workbench run lint
npm --prefix apps/workbench run test -- --run
npm --prefix apps/workbench run build

# 3. Playwright E2E(自动拉起 vite dev 并代理 /api 到 localhost:8000)
npm --prefix apps/workbench run test:e2e
```

- 种子:`POST /api/e2e/seed`(仅演示入口注册)幂等创建 `e2e-operator` 账号、工作区 `品牌一`、店铺 `淘宝旗舰店`、商品 `SKU-001`(初始价 128.00 CNY),并复位运行面数据。
- Playwright 配置 `retries: 0`,禁止重试后侥幸通过。
