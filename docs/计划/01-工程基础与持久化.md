# 工程基础与持久化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立可运行的 Python 工程、PostgreSQL 持久化基础、Runtime 公共类型、Workspace 身份边界、Secret 与端点安全。

**Architecture:** 使用根包 `runtime` 承载公共接口和内部服务，SQLAlchemy/Alembic 仅出现在持久化层。Repository 不自行提交事务，Application Service 拥有事务边界；所有 Workspace 数据查询显式携带 `workspace_id`。

**Tech Stack:** Python 3.12, uv, Pydantic v2, SQLAlchemy 2, Alembic, PostgreSQL 16 + pgvector, pytest, pytest-asyncio, Ruff, mypy, PyJWT, argon2-cffi, cryptography

- [ ] **Step 3: 实现强类型公共模型**

`RunStatus` 定义 `QUEUED/RUNNING/WAITING_INPUT/WAITING_CONFIRMATION/WAITING_RECONCILIATION/COMPLETED/FAILED/CANCELLED`，并以显式集合实现 `is_terminal`。`ResourceScope` 使用 `mode=ALL|SELECTED` 与不可变 `resource_ids` 表达通用资源范围，`SELECTED` 不允许空集合。`ToolDefinition` 使用 `ConfigDict(extra="forbid", frozen=True)`，不得存放 Handler 或 Secret。

```python
class RunStatus(str, Enum):
    QUEUED = "QUEUED"
    RUNNING = "RUNNING"
    WAITING_INPUT = "WAITING_INPUT"
    WAITING_CONFIRMATION = "WAITING_CONFIRMATION"
    WAITING_RECONCILIATION = "WAITING_RECONCILIATION"
    COMPLETED = "COMPLETED"
    FAILED = "FAILED"
    CANCELLED = "CANCELLED"

    @property
    def is_terminal(self) -> bool:
        return self in {self.COMPLETED, self.FAILED, self.CANCELLED}


class ResourceScope(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    mode: Literal["ALL", "SELECTED"]
    resource_ids: frozenset[str] = frozenset()

    @model_validator(mode="after")
    def validate_selected_scope(self) -> "ResourceScope":
        if self.mode == "SELECTED" and not self.resource_ids:
            raise ValueError("SELECTED scope requires resource ids")
        return self
```

- [ ] **Step 3: 实现 UnitOfWork 和显式 Workspace Repository**

```python
class UnitOfWork(Protocol):
    workspaces: WorkspaceRepository
    sessions: SessionRepository
    runs: RunRepository
    jobs: JobRepository
    requests: RequestRepository
    events: EventRepository

    async def __aenter__(self) -> "UnitOfWork":
        raise NotImplementedError

    async def __aexit__(self, exc_type, exc, tb) -> None:
        raise NotImplementedError

    async def commit(self) -> None:
        raise NotImplementedError

    async def rollback(self) -> None:
        raise NotImplementedError
```

SQLAlchemy 实现在 `__aenter__` 创建 AsyncSession，正常退出不自动提交，异常退出执行 rollback 并关闭 Session。Repository 只调用 `flush`，不调用 `commit`。CAS Update 必须同时比较 `workspace_id`、当前状态和 `state_version`。
