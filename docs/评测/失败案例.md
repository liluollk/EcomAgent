# 失败案例

本文件记录当前固定协议下真实模型评测中已经复现的失败，用于归因和构建 Regression。

## 当前状态

尚未运行 Development 真实模型评测，因此当前没有可进入 Regression 的 Bad Case。`regression.yaml` 保持为空。

## 记录模板

| 状态 | Case | 失败现象 | 证据 | 根因 | 修复 | 复跑结果 |
| --- | --- | --- | --- | --- | --- | --- |
| Open / Closed | `case-id` | 可复现的任务失败 | Report 与 Trace | 已验证归因 | 代码、Prompt、Tool Schema 或场景修正 | 固定协议下的重复运行结果 |

## 纳入 Regression 的条件

1. 失败来自真实模型运行，不是 Provider 401、连接失败或依赖不可用。
2. 有一条最小、稳定复现的场景，预期最终状态和必要证据明确。
3. 已通过 Trace 将问题归因到模型决策、Prompt/Skill、Tool Schema、业务处理或评分逻辑。
4. 修复后在固定协议下重复运行通过。
5. 场景加入 `regression.yaml`，同步 manifest，并与其他分区保持 ID 互斥。

同一根因的多次重复失败只记为一个 Bad Case，不用重复运行次数扩充案例数量。
