# OceanBreeze 电商运营 Agent — 展示版

本目录是独立可跑的前端展示版，**无需启动后端**即可完整交互（所有接口数据由内置 mock 层提供）。适合演示、评审、或离线体验。

## 快速开始

```bash
# 进入展示版目录
cd demo/frontend

# 安装依赖（首次运行）
npm install

# 启动展示版（默认 mock 模式，不需要后端）
npm run dev
```

打开 `http://localhost:5173` 即可体验展示版主流程：对话流、工具调用卡片、权限确认卡、设置页（渠道/模型 CRUD）、工作台看板等。主流程和视觉语言与可交付版一致，但展示版不包含可交付版的业务规则设置页。

## 展示的主流程

展示版演示的是**多平台商品调价闭环**，与后端默认 Agent 的模型可见工具一致：

```
查快照 → 提交目标价 → 审批 → 执行 → 平台结果回查
```

默认只有两个业务工具：`query_product_snapshot`（当前价 / 库存 / 状态 / 进行中活动与活动锁价）与 `update_price`（走完整调价闭环，**是否生效以平台回查为准**），外加 `save_skill` 元技能。内置的 mock 会话覆盖四类结果：

| 会话 | 场景 | 结果 |
|---|---|---|
| demo-001 | 淘宝改价 | 成功，含「平台回查一致」 |
| demo-002 | 抖店改价 | 成功，同一商品跨平台价差提示 |
| demo-003 | 低于成本的调价 | 成本保护拦截，零写入 |
| demo-004 | 活动中的 SKU 改价 | 平台活动锁价拦截 |

其余内置技能（工单、知识库、经营分析、上下架等）依赖默认 Agent 未注册的扩展工具，技能列表里用「需扩展工具」标记，正文也显式声明了这一点。

**展示数据来自内置 mock 层**：平台协议、商品价格与库存、故障与回查结果都是本地模拟，用于演示交互与闭环语义，不代表已接入任何真实电商平台。

## 运行模式

展示版支持两种运行模式，由环境变量 `VITE_OBS_MOCK` 控制：

| 模式 | VITE_OBS_MOCK | 说明 |
|------|---------------|------|
| **Mock 独立（默认）** | `1`（或未设置） | 前端内置假数据 + mock 事件流，无需任何后端，全部接口在该层模拟 |
| **连接真实后端** | `0` | 前端连接项目根后端的真实 HTTP/WS 接口（需要后端已启动） |

### 连接真实后端

```bash
# 1. 启动项目根后端（mock 模式或真实 LLM 皆可）
cd ../..
AGENT_BACKEND=mock python -m uvicorn transport.server:app --port 8000

# 2. 在新的终端中启动展示版（连接后端模式）
cd demo/frontend
VITE_OBS_MOCK=0 npm run dev
```

此时展示版前端通过 Vite 开发服务器将 `/sessions`、`/ws` 等请求转发到后端 `:8000`，体验真实 HTTP/WebSocket 交互。

## 构建产物

```bash
npm run build
```

产物输出到 `demo/frontend/dist/`，可用 `npm run preview` 或任意静态服务器托管。

## 与可交付版的关系

- **展示版（`demo/frontend/`）**：冻结的独立展示前端，内置 mock 数据层，可独立运行。UI 与可交付版一致。
- **可交付版（`frontend/`）**：连接后端真实 API 的前端，无 mock 数据，用于真实部署。
- **后端（`transport/` 等）**：完整 REST/WS 接口，与展示版的 mock 接口形状一致（切换 `VITE_OBS_MOCK=0` 后展示版即可对接后端实际接口）。
